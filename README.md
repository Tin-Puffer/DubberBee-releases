# Dubber Bee — bản phát hành

Lồng tiếng video Trung → Việt tự động, chạy trên máy tính (macOS, Windows).

## Tải về

Vào [Releases](https://github.com/Tin-Puffer/DubberBee-releases/releases/latest) và tải:

- **macOS** (Apple Silicon): `Dubber-macos.zip` → giải nén, kéo `Dubber.app` vào *Applications*.
  Lần đầu mở: chuột phải → **Open** (app chưa được Apple chứng nhận).
- **Windows 10/11 x64**: `Dubber-windows.zip` → giải nén vào thư mục ngắn (vd. `C:\Dubber`),
  chạy `Dubber\Dubber.exe`. SmartScreen chặn → **More info → Run anyway**.

Lần đầu mở, app tự tải dữ liệu (~1,8 GB) — chỉ một lần. Khi có bản mới, app tự hỏi và tự cập nhật.

---

Repo này chỉ chứa file phát hành (app + models), app đọc trực tiếp từ đây để tải models và
kiểm tra bản mới. Release `models-v1` là dữ liệu models — đừng xóa.
